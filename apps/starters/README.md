# Eniem Starters

Example projects demonstrating specific Eniem use cases. Each starter is a standalone Next.js application you can clone and run independently.

## Available Starters

| Starter | Description |
|---------|-------------|
| [eniem-polar-benefits](./eniem-polar-benefits/) | Demonstrates Polar benefits integration — downloadables, GitHub repo access, and subscription management. |

## Usage

```bash
git clone https://github.com/eniem-dev/eniem-starters
cd eniem-starters/<starter-name>
pnpm install
cp .env.example .env
# Fill in your environment variables
pnpm dev
```

Each starter has its own README with detailed setup instructions.
