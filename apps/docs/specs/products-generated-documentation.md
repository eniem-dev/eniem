# Products Generated Documentation

## Overview

Document the `products.generated.ts` file implementation for the eniem-doc site, explaining how pricing table components and plan selection checkout consume this auto-generated file to display products and initiate purchases.

## Job to Be Done

Help developers using the Eniem boilerplate understand how `products.generated.ts` serves as the single source of truth for pricing display, and how components consume this data to render pricing tables and handle checkout flows.

## Target User

End users/developers using the Eniem boilerplate who want to understand how pricing data flows from configuration to UI components.

## Requirements

### Must Have

- [ ] Explain that `products.generated.ts` is auto-generated by `sync-products.ts` CLI
- [ ] Document the `GeneratedProduct` interface and `ProductDisplay` type
- [ ] Show how `getDisplayProducts()` filters products for pricing page display
- [ ] Explain component data flow: products.generated.ts -> PricingPage/ChoosePlanPage -> PricingCard
- [ ] Document how `BuyButton` initiates checkout using product slug
- [ ] Explain the difference between `sandboxProducts` and `productionProducts`
- [ ] Show how environment config (`env.payment.polarServer`) selects the correct product set

### Nice to Have

- [ ] Brief mention of `getCheckoutProducts()` for BetterAuth integration
- [ ] Reference to the CLI documentation for product sync

## Constraints

- Keep focus on consumption, not on CLI/sync internals (separate doc exists for that)
- Avoid code duplication with existing subscription/one-time docs
- Use concise explanations matching the existing documentation style

## Acceptance Criteria

- [ ] Documentation explains the data flow from products.generated.ts to UI components
- [ ] Code snippets show actual usage from the boilerplate (PricingPage, ChoosePlanContent)
- [ ] Developer understands where product display data comes from
- [ ] Developer understands how BuyButton connects to checkout

## Edge Cases

- Products with empty features array are filtered out by `getDisplayProducts()`
- Products without `polarProductId` cannot complete checkout (filtered by `getCheckoutProducts()`)

## Out of Scope

- CLI usage for `sync-products.ts` (reference to separate CLI doc)
- JSON schema configuration details
- Webhook handling and subscription sync
- Polar API integration details
