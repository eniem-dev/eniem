The recommended way to get started is using the Eniem CLI. For manual git clone setup, see [Manual Installation](/getting-started/manual-installation).

```bash
npx eniem-cli@latest [YOUR_APP_NAME]
cd [YOUR_APP_NAME]
pnpm db:start
pnpm db:migrate
pnpm dev
```

> Eniem requires Node 18.17 or greater. Type `node -v` in your terminal to check version.

**Using pnpm or bun?**

```bash
# pnpm
pnpm dlx eniem-cli@latest [YOUR_APP_NAME]

# bun
bunx eniem-cli@latest [YOUR_APP_NAME]
```

Open [http://localhost:3000](http://localhost:3000) to see your site.

## Configure Products

After setting up your app, configure your Polar products using the CLI:

```bash
eni products
```

This interactive wizard lets you create subscription and one-time payment products, sync them to Polar, and generate `products.generated.ts` with TypeScript types for your pricing UI.

**How it works:** The CLI syncs your products from Polar and generates `products.generated.ts`. This file exports functions like `getCheckoutProducts()` that your auth configuration and pricing components consume—keeping your UI automatically in sync with Polar without manual product ID management.

See the [CLI Products guide](/guides/cli) for full documentation, or [Product Configuration](/payments/products-generated) to understand how product data flows through your app.

## Useful commands

- `pnpm dev` — Start development server
- `pnpm build` — Build for production
- `pnpm db:start` — Start PostgreSQL container
- `pnpm db:stop` — Stop PostgreSQL container
- `pnpm db:studio` — Open Prisma Studio

### AI Workflow

Plan and build features autonomously with the `eni` CLI:

- `eni plan` — Generate beads tasks from a spec
- `eni plan --spec=<name>` — Plan a specific spec
- `eni build` — Build one task from the plan
- `eni build --spec=<name> --iterations=20` — Build autonomously (custom iterations)

See the [AI Workflow guide](/guides/ai-workflow) for full documentation.
