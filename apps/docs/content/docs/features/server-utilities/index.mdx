## Why Server Utilities?

Direct database calls and authentication checks scattered throughout your codebase lead to:

- **Inconsistent error handling** across different endpoints
- **Repeated authentication boilerplate** in every protected route
- **Type safety gaps** between client and server responses
- **Difficult debugging** without standardized logging

Server utilities solve this with a single builder that provides:

- Automatic session management and type inference
- Consistent response formats (`Result<T>` and `ApiResponse<T>`)
- Centralized error classification with proper HTTP status codes
- Built-in logging at the right level (warn for 4xx, error for 5xx)

## Overview

A single builder lives in `lib/handler.ts` and exposes two roots and three terminals:

| Root       | Ctx                                  |
| ---------- | ------------------------------------ |
| `authed`   | `{ user, session }` guaranteed non-null |
| `publicly` | `{ user: null, session: Session \| null }` |

| Terminal    | Returns                                |
| ----------- | -------------------------------------- |
| `.query()`  | `() => Promise<Result<T>>` for RSC     |
| `.action()` | A next-safe-action client              |
| `.route()`  | A Next.js route handler                |

Chain `.input(schema)` to parse Zod input into `ctx.input`.

## Response Types

### Result (for Queries)

```ts
type Result<T> =
  | { data: T; error: null }
  | { data: null; error: string };
```

### ApiResponse (for API Routes)

```ts
type ApiResponse<T> =
  | { success: true; data: T }
  | { success: false; error: string };
```

## Queries

Queries are for **server-side data fetching** in React Server Components. They return a `Result<T>`.

### Public query

For public data that doesn't require authentication:

```ts
// features/posts/queries/posts.query.ts
import { publicly } from "@/lib/handler";

export const getPublicPosts = () =>
  publicly.query(async ({ session }) => {
    const posts = await prisma.post.findMany({
      where: { published: true },
    });

    return {
      posts,
      isAuthenticated: !!session?.user,
    };
  });
```

Usage in a page:

```tsx
// app/posts/page.tsx
import { getPublicPosts } from "@/features/posts";

export default async function PostsPage() {
  const { data, error } = await getPublicPosts();

  if (error) {
    return <ErrorMessage message={error} />;
  }

  return <PostList posts={data.posts} />;
}
```

### Authenticated query

For protected data where authentication is required:

```ts
// features/user/queries/user.query.ts
import { authed } from "@/lib/handler";

export const getCurrentUser = () =>
  authed.query(async ({ user }) => {
    const profile = await prisma.user.findUnique({
      where: { id: user.id },
      include: { preferences: true },
    });

    return profile;
  });
```

Usage in a protected page:

```tsx
// app/dashboard/page.tsx
import { getCurrentUser } from "@/features/user";
import { redirect } from "next/navigation";

export default async function DashboardPage() {
  const { data, error } = await getCurrentUser();

  if (error) {
    redirect("/auth/signin");
  }

  return <Dashboard user={data} />;
}
```

## Server Actions

Server actions are for **mutations and form submissions**. Chain `.input(schema).action(...)`.

### Public action

```ts
// features/newsletter/actions/subscribe.action.ts
"use server";

import { publicly } from "@/lib/handler";
import { z } from "zod";
import { locales } from "@/locales";

const subscribeSchema = z.object({
  email: z.string().email(locales.errors.invalidEmail),
});

export const subscribeAction = publicly
  .input(subscribeSchema)
  .action(async ({ input }) => {
    await prisma.subscriber.create({ data: { email: input.email } });
    return { message: locales.success.subscribed };
  });
```

### Authenticated action

```ts
// features/user/actions/update-profile.action.ts
"use server";

import { authed } from "@/lib/handler";
import { updateProfileSchema } from "../schemas/profile.schema";
import { logger } from "@/lib/logger";
import { revalidatePath } from "next/cache";

export const updateProfileAction = authed
  .input(updateProfileSchema)
  .action(async ({ input, user }) => {
    logger.info("Updating user profile", { userId: user.id });

    await prisma.user.update({
      where: { id: user.id },
      data: { name: input.name, bio: input.bio },
    });

    revalidatePath("/dashboard/profile");
    return { success: true };
  });
```

### Using Actions in Components

Use the `useAction` hook from `next-safe-action`:

```tsx
"use client";

import { useAction } from "next-safe-action/hooks";
import { updateProfileAction } from "@/features/user";
import { isActionSuccessful } from "@/lib/safe-action";
import { toast } from "sonner";

export function ProfileForm() {
  const { execute, isPending } = useAction(updateProfileAction, {
    onSuccess: ({ data }) => {
      if (isActionSuccessful(data)) {
        toast.success("Profile updated!");
      }
    },
    onError: ({ error }) => {
      toast.error(error.serverError ?? "Something went wrong");
    },
  });

  const handleSubmit = (formData: FormData) => {
    execute({
      name: formData.get("name") as string,
      bio: formData.get("bio") as string,
    });
  };

  return (
    <form action={handleSubmit}>
      {/* form fields */}
      <button type="submit" disabled={isPending}>
        {isPending ? "Saving..." : "Save"}
      </button>
    </form>
  );
}
```

## API Routes

API routes are for **REST endpoints** consumed by external clients.

### Public route

```ts
// app/api/posts/route.ts
import { publicly } from "@/lib/handler";

export const GET = publicly.route(async () => {
  const posts = await prisma.post.findMany({ where: { published: true } });
  return { posts, count: posts.length };
});
```

### Authenticated route

Returns 401 automatically if the user is not authenticated. Chain `.input(schema)` to parse the JSON body (for non-GET) or query string (for GET) into `ctx.input`.

```ts
// app/api/posts/route.ts
import { authed } from "@/lib/handler";
import { z } from "zod";

const createPostSchema = z.object({
  title: z.string().min(1),
  content: z.string(),
});

export const POST = authed
  .input(createPostSchema)
  .route(async ({ user, input }) => {
    const post = await prisma.post.create({
      data: { ...input, authorId: user.id },
    });
    return { post };
  });
```

### Response Format

All API routes return a consistent JSON structure:

```json
// Success
{ "success": true, "data": { "posts": [...] } }

// Error
{ "success": false, "error": "Unauthorized" }
```

## Utility Functions

### isActionSuccessful

Use with `next-safe-action` results. Returns `true` only if there's no `serverError` and no `validationErrors`.

```ts
import { isActionSuccessful } from "@/lib/safe-action";

const result = await subscribeAction({ email: "user@example.com" });

if (isActionSuccessful(result)) {
  console.log(result.data);
}
```

### resolveActionResult

Converts an action result into a standard Promise that resolves with data or rejects with the error message.

```ts
import { resolveActionResult } from "@/lib/safe-action";

try {
  const data = await resolveActionResult(
    subscribeAction({ email: "user@example.com" })
  );
} catch (error) {
  // error is the serverError message
}
```

## Best Practices

### 1. Choose the Right Terminal

| Need               | Use                  |
| ------------------ | -------------------- |
| Fetch data in RSC  | `.query()`           |
| Form submission    | `.action()`          |
| External API       | `.route()`           |

### 2. Always Use `authed` for Protected Data

Avoid manual auth checks inside handlers. `authed.*` guarantees `user` is non-null with proper TypeScript types.

```ts
// ❌ Bad - manual auth check
export const getProfile = () =>
  publicly.query(async ({ session }) => {
    if (!session?.user) throw new UnauthorizedError();
    // ...
  });

// ✅ Good - use authed
export const getProfile = () =>
  authed.query(async ({ user }) => {
    // user is guaranteed non-null
  });
```

### 3. Use Locales for Error Messages

```ts
import { locales } from "@/locales";

throw new ValidationError(locales.errors.emailAlreadyExists);
```

### 4. Log Important Operations

```ts
import { logger } from "@/lib/logger";

export const deleteAccount = authed.action(async ({ user }) => {
  logger.info("Deleting user account", { userId: user.id });
  // ...
});
```

### 5. Revalidate After Mutations

```ts
import { revalidatePath, revalidateTag } from "next/cache";

export const updatePost = authed
  .input(updatePostSchema)
  .action(async ({ input }) => {
    await prisma.post.update({ /* ... */ });

    revalidatePath("/posts");
    revalidateTag("posts");
  });
```
