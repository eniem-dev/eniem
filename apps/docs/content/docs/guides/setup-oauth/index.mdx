## Prerequisites

- Completed the [Installation](/getting-started/installation) guide
- A GitHub or Twitter developer account

## Steps

### 1. Create OAuth Application

#### For GitHub:

1. Go to [GitHub Developer Settings](https://github.com/settings/developers)
2. Click **New OAuth App**
3. Fill in the details:
   - **Application name**: Your app name
   - **Homepage URL**: `http://localhost:3000` (or your production URL)
   - **Authorization callback URL**: `http://localhost:3000/api/auth/callback/github`
4. Click **Register application**
5. Copy the **Client ID**
6. Click **Generate a new client secret** and copy it

#### For Twitter/X:

1. Go to [Twitter Developer Portal](https://developer.twitter.com/en/portal/dashboard)
2. Create a new project and app
3. In **User authentication settings**, enable OAuth 2.0
4. Set the **Redirect URI**: `http://localhost:3000/api/auth/callback/twitter`
5. Copy the **Client ID** and **Client Secret**

### 2. Add Environment Variables

Add the credentials to your `.env` file:

```bash
# GitHub OAuth
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

# Twitter OAuth
TWITTER_CLIENT_ID=your_twitter_client_id
TWITTER_CLIENT_SECRET=your_twitter_client_secret
```

## Test It

1. Start your development server: `pnpm dev`
2. Navigate to login or signup page
3. Click the OAuth button
4. You should be redirected to GitHub/Twitter to authorize
5. After authorization, you'll be redirected back and logged in
