## Prerequisites

- Completed the [Installation](/getting-started/installation) guide
- A [Polar.sh](https://polar.sh) account

## Steps

### 1. Create Polar Access Token

1. Go to [Polar.sh](https://polar.sh) and sign in
2. Navigate to **Organization Settings → Developers**
3. Click **Create Token**
4. Name it (e.g., `eniem-sandbox`)
5. Select the required permissions based on your needs:

**Core Scopes (Always Required)**

These scopes are needed for basic subscription functionality:

- `checkouts:write` - Create checkout sessions
- `customers:read` - Read customer info and state
- `customers:write` - Create/delete customers
- `customer_portal:read` - View subscriptions, orders
- `customer_portal:write` - Manage customer account
- `orders:read` - View order history
- `subscriptions:read` - View subscription details

**Benefits Scopes (Optional)**

Add these if you're using GitHub benefits or downloadables:

- `benefits:read` - View benefit information
- `customer_sessions:write` - Create portal session tokens
- `files:read` - Access downloadable files

**Usage-Based Billing (Optional)**

Add these if you're using usage-based pricing:

- `customer_meters:read` - Read usage meters
- `events:write` - Record usage events

> **Note:** Only select the scopes you actually need. The core scopes are sufficient for basic subscription functionality. Add the optional scopes only if you're using those specific features.

6. Copy the generated token

### 2. Add Environment Variables

Configure your environment with the Polar credentials:

```bash
POLAR_ACCESS_TOKEN=your_access_token_here
POLAR_SERVER=production  # Use 'production' for live payments
POLAR_WEBHOOK_SECRET=your_webhook_secret_here
```

### 3. Create a Subscription Product

> **Recommended:** Use the [Eniem CLI](/guides/cli) to manage products. The CLI automatically syncs product data to `products.generated.ts`, which is used by the checkout system and pricing components.

**Option A: Using the CLI (Recommended)**

```bash
eni products
```

Select **Add** to create a new product via the wizard, then **Sync** to push to Polar. The CLI generates `products.generated.ts` with all product data, eliminating manual configuration.

**Option B: Manual Creation**

1. In Polar, go to **Products → New Product**
2. Configure your product and set pricing to **Recurring subscription**
3. Set your pricing (monthly/yearly)
4. Copy the **Product ID** from the product page URL
5. Manually configure products in `products.config.json` and run `eni products` → **Sync**

### 4. Configure the Checkout in Auth

The checkout plugin uses `getCheckoutProducts()` from `products.generated.ts` to automatically load your products. This file is generated by the CLI at `src/features/billing/generated/products.generated.ts` when you sync products.

In `/lib/auth.ts`:

```typescript
import { env } from "@/config";
import { getCheckoutProducts } from "@/features/billing/generated/products.generated";

polar({
  client: polarClient,
  createCustomerOnSignUp: true,
  use: [
    checkout({
      products: getCheckoutProducts(env.payment.polarServer),
      successUrl: "/success?checkout_id={CHECKOUT_ID}",
      authenticatedUsersOnly: true,
    }),
    portal(),
    webhooks({
      secret: env.payment.polarWebhookSecret,
      // ... webhook handlers
    }),
  ],
});
```

This approach keeps your auth configuration in sync with your product definitions automatically.

### 5. Use BuyButton

The `BuyButton` component initiates checkout using the product slug:

```tsx
import { BuyButton } from "@/components/buy-button";

<BuyButton slug="pro-monthly" label="Subscribe" />;
```

The slug must match a product defined in your `products.config.json` and synced via the CLI.

### 6. Set Up Webhook (Production)

1. In Polar, go to **Organization Settings → Webhooks**
2. Add your webhook URL: `https://yourdomain.com/api/auth/polar/webhooks`
3. Copy the webhook secret to your environment variables

## Test It

1. Start your dev server: `pnpm dev`
2. Sign in to your application
3. Click the subscribe button
4. Complete the checkout with Polar's test card: `4242 4242 4242 4242`
5. You should be redirected to your success page

## Sandbox

All the above steps can be tested in Polar's sandbox environment by setting `POLAR_SERVER=sandbox` in your environment variables and make the same configuration on https://sandbox.polar.sh/.

For the webhook in local development, you can use a tool like [ngrok](https://ngrok.com/) to expose your local server to the internet.
