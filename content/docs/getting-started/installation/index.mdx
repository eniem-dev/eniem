## Quick Start (Recommended)

The fastest way to get started is using the Eniem CLI:

```bash
npx eniem-cli@latest [YOUR_APP_NAME]
cd [YOUR_APP_NAME]
pnpm db:start
pnpm db:migrate
pnpm dev
```

> Eniem requires Node 18.17 or greater. Type `node -v` in your terminal to check version.

**Using pnpm or bun?**

```bash
# pnpm
pnpm dlx eniem-cli@latest [YOUR_APP_NAME]

# bun
bunx eniem-cli@latest [YOUR_APP_NAME]
```

Open [http://localhost:3000](http://localhost:3000) to see your site. And voila!

## Manual Installation

If you prefer to set up manually:

**1. Clone the repository:**

```bash
git clone https://github.com/eniem-dev/eniem-boilerplate [YOUR_APP_NAME]
cd [YOUR_APP_NAME]
```

**2. Remove git history and reinitialize:**

```bash
git remote remove origin && rm -rf .git && git init
```

**3. Install dependencies:**

```bash
pnpm install
```

**4. Rename `.env.example` to `.env`:**

```bash
mv .env.example .env
```

**5. Start the database:**

```bash
pnpm db:start
```

**6. Run migrations:**

```bash
pnpm db:migrate
```

**7. Start the dev server:**

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see your site.

### Configure .env

> Skip this if you used the CLI — it handles `.env` setup automatically.

Change `BETTER_AUTH_SECRET` to a random string (use `openssl rand -base64 32`). The file content should look like this:

```bash
# Project Configuration
PROJECT_URL=http://localhost:3000
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME=eniem

# Better Auth Configuration
BETTER_AUTH_SECRET=your-random-secret-here
BETTER_AUTH_URL=http://localhost:3000

# Database Configuration (PostgreSQL)
DATABASE_URL=postgresql://eniem:eniem-dev-password@localhost:5432/eniem

# OAuth (optional)
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
TWITTER_CLIENT_ID=
TWITTER_CLIENT_SECRET=

# Polar (for payments)
POLAR_ACCESS_TOKEN=
POLAR_SERVER=sandbox
POLAR_WEBHOOK_SECRET=

# Resend (for emails)
RESEND_API_KEY=
EMAIL_FROM_ADDRESS=no-reply@yourdomain.com
```

## Useful commands

- `pnpm dev` — Start development server
- `pnpm build` — Build for production
- `pnpm db:start` — Start PostgreSQL container
- `pnpm db:stop` — Stop PostgreSQL container
- `pnpm db:studio` — Open Prisma Studio

### Ralph (AI-driven development)

- `pnpm feature:list` — List available implementations
- `pnpm feature:create` — Create new feature (interactive planning)
- `pnpm feature:implement -- <name>` — Implement a feature
- `pnpm feature:implement-once -- <name>` — Single iteration

See the [Ralph guide](/guides/ralph) for full documentation.
