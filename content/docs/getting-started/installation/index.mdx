The recommended way to get started is using the Eniem CLI. For manual git clone setup, see [Manual Installation](/getting-started/manual-installation).

```bash
npx eniem-cli@latest [YOUR_APP_NAME]
cd [YOUR_APP_NAME]
pnpm db:start
pnpm db:migrate
pnpm dev
```

> Eniem requires Node 18.17 or greater. Type `node -v` in your terminal to check version.

**Using pnpm or bun?**

```bash
# pnpm
pnpm dlx eniem-cli@latest [YOUR_APP_NAME]

# bun
bunx eniem-cli@latest [YOUR_APP_NAME]
```

Open [http://localhost:3000](http://localhost:3000) to see your site.

## Configure Products

After setting up your app, configure your Polar products using the CLI:

```bash
eniem products
```

This interactive wizard lets you create subscription and one-time payment products, sync them to Polar, and generate TypeScript types for your pricing UI. See the [CLI Products guide](/guides/cli) for full documentation.

## Useful commands

- `pnpm dev` — Start development server
- `pnpm build` — Build for production
- `pnpm db:start` — Start PostgreSQL container
- `pnpm db:stop` — Stop PostgreSQL container
- `pnpm db:studio` — Open Prisma Studio

### Ralph (AI-driven development)

Ralph uses `loop.sh` for autonomous feature implementation:

- `pnpm ralph:plan` — Generate implementation plan from all specs
- `pnpm ralph:plan-work "desc"` — Generate scoped implementation plan
- `pnpm ralph:build` — Build one task from the plan
- `pnpm ralph:build:auto` — Build autonomously (10 iterations)

For interactive mode, use `./loop.sh` directly:

```bash
./loop.sh plan -i      # Plan with interactive output
./loop.sh build 5 -i   # Build 5 iterations interactively
```

See the [Ralph guide](/guides/ralph) for full documentation.
