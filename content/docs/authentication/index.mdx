ENIEM uses [BetterAuth](https://www.better-auth.com/docs) for authentication, providing a flexible and secure foundation for multiple auth strategies.

## Documentation

#### [Email/Password](/authentication/email-password)

Traditional email and password authentication with password reset flow.

#### [Passwordless](/authentication/passwordless)

OTP-based authentication without passwords.

#### [OAuth](/authentication/oauth)

Social login with GitHub, Twitter/X, and other providers.

#### [SIWE](/authentication/siwe)

Sign In With Ethereum for Web3 wallet authentication.

#### [Rate Limits](/authentication/rate-limits)

Protection against brute-force and abuse attacks.
