A quick reminder of security essentials before going live.

## Environment & Secrets

- [ ] All secrets in `.env` (never committed to git)
- [ ] `BETTER_AUTH_SECRET` is a strong random string (32+ chars)
- [ ] Database credentials are production-ready
- [ ] OAuth provider secrets are set for production
- [ ] Polar webhook secret is configured

## Authentication

- [ ] [Rate limiting](/authentication/rate-limits) is enabled
- [ ] Email verification is required before sign-in
- [ ] Password reset tokens expire (default: 1 hour)
- [ ] OTP codes have attempt limits (default: 3 attempts)

## Access Control

- [ ] [Protected routes](/project-configuration/page-level-access) use middleware
- [ ] Server actions use `authenticatedActionClient`
- [ ] API routes use `createAuthenticatedApiHandler`

## File Uploads

- [ ] [File validation](/features/file-upload) on both client and server
- [ ] File size limits enforced
- [ ] MIME type checking enabled
- [ ] Files stored in user-isolated folders

## Deployment

- [ ] HTTPS enforced (no HTTP in production)
- [ ] Database connection uses SSL
- [ ] Error messages don't expose stack traces
- [ ] Debug/development features disabled

## External Services

- [ ] Polar environment set to production
- [ ] Webhook endpoints verify signatures
- [ ] Email provider (Resend) configured for production domain

## Framework Protections

These are handled automatically but worth knowing:

| Protection | Handled By |
|------------|------------|
| CSRF | Next.js Server Actions |
| XSS | React auto-escaping |
| SQL Injection | Prisma ORM |

## Quick Audit Commands

```bash
# Check for exposed secrets
git log --all --full-history -- "*.env*"

# Audit dependencies
pnpm audit

# Check for TODO/FIXME in security-sensitive areas
grep -r "TODO\|FIXME" src/lib/auth src/features/auth
```
