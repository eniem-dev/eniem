## Prerequisites

- Completed the [Installation](/getting-started/installation) guide
- A [WalletConnect](https://cloud.walletconnect.com/) project ID

## Steps

### 1. Get WalletConnect Project ID

1. Go to [WalletConnect Cloud](https://cloud.walletconnect.com/)
2. Create a new project
3. Copy the **Project ID**

### 2. Add Environment Variable

```bash
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=your_project_id_here
```

## Test It

1. Start your dev server: `pnpm dev`
2. Go to login or signup page
3. Click "Sign in with Ethereum"
4. Connect your wallet and Sign the message in your wallet
5. You should be authenticated and redirected

## Theme Customization

RainbowKit automatically syncs with your app's light/dark theme. To customize colors, update `/lib/rainbowkit-theme.ts`.
