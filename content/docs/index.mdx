Welcome to Eniem, an opinionated boilerplate for building applications quickly with Next.js, BetterAuth, and Polar.

## What is Eniem?

Eniem provides a solid foundation for building modern web applications with:

- **Next.js** with App Router and Turbopack
- **BetterAuth** for authentication (Email/Password, OAuth, Web3)
- **Polar** for subscriptions and payments
- **PostgreSQL** with Prisma ORM
- **shadcn/ui** components with Tailwind CSS
- **Type-safe server actions** with NextSafeAction

## Features Overview

- **Authentication**: Email/password, GitHub, Twitter/X, and Web3 (SIWE)
- **Payments**: Subscriptions, one-time purchases
- **Analytics**: PostHog integration for product analytics
- **Email**: Resend with React Email templates
- **Storage**: DigitalOcean Spaces for file uploads
- **Landing Mode**: Toggle landing page for pre-launch
