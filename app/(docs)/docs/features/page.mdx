# Features

Built-in utilities and integrations to accelerate your development.

## [Landing Mode](/docs/features/landing-mode)

Pre-launch landing page with email collection and animated UI.

## [Server Utilities](/docs/features/server-utilities)

Type-safe server queries, API handlers, and authentication wrappers.

## [Emails](/docs/features/emails)

Transactional emails with Resend and React Email components.

## [Analytics](/docs/features/analytics)

Event tracking abstraction layer (provider-agnostic).

## [File Upload](/docs/features/file-upload)

Image uploads to DigitalOcean Spaces with automatic organization.
