# Self-Hosted Deployment (Coolify)

Deploy your Eniem application on your own infrastructure using Coolify.

## Prerequisites

Before you begin, make sure you have:

- A server with Coolify installed ([Coolify installation guide](https://coolify.io/docs/installation))
- A PostgreSQL database (can be deployed via Coolify)
- A domain name pointing to your server

---

## Step 1: Create a New Project

1. Log into your Coolify dashboard
2. Click **New Project**
3. Give your project a name (e.g., "eniem-production")

---

## Step 2: Add Your Application

1. In your project, click **Add Resource** → **Application**
2. Select **GitHub** (or GitLab/Bitbucket)
3. Connect your repository
4. Select the branch to deploy (usually `main`)

### Build Configuration

Configure the following settings:

| Setting | Value |
|---------|-------|
| Build Pack | Nixpacks |
| Build Command | `pnpm build` |
| Start Command | `pnpm start` |
| Port | `3000` |

---

## Step 3: Configure Environment Variables

Add your production environment variables in the **Environment Variables** section.

See the [Deployments Overview](/docs/deployments) for the full list of required variables.

> **Important:** Make sure `DATABASE_URL` points to your PostgreSQL instance.

---

## Step 4: Set Up Database

If you haven't already, deploy a PostgreSQL database:

1. In your project, click **Add Resource** → **Database**
2. Select **PostgreSQL**
3. Configure the database name and credentials
4. Copy the connection string for your `DATABASE_URL`

---

## Step 5: Run Migrations

After the first deployment, you need to run database migrations.

### Option A: Post-Deploy Command

In Coolify, add a post-deploy command:

```bash
pnpm db:migrate && pnpm db:generate
```

### Option B: Manual Migration

SSH into your server and run:

```bash
cd /path/to/your/app
pnpm db:migrate
```

---

## Step 6: Configure Domain

1. Go to your application settings in Coolify
2. Add your domain under **Domains**
3. Enable **HTTPS** (Coolify handles SSL via Let's Encrypt)

---

## Cloudflare Tunnel (Optional)

If your server is behind a firewall or you want additional security, you can use Cloudflare Tunnel:

1. Install `cloudflared` on your server
2. Create a tunnel: `cloudflared tunnel create eniem`
3. Configure the tunnel to point to `localhost:3000`
4. Add DNS records in Cloudflare

---

## Updating Your Application

Coolify supports automatic deployments:

1. **Webhook**: Triggered on every push to your branch
2. **Manual**: Click **Deploy** in the Coolify dashboard

---

## Troubleshooting

### Application won't start

- Check the logs in Coolify dashboard
- Verify all required environment variables are set
- Ensure the database is accessible

### Database connection errors

- Verify `DATABASE_URL` is correct
- Check if the database container is running
- Ensure network connectivity between app and database

### Build failures

- Check if all dependencies are in `package.json`
- Verify Node.js version compatibility
- Review build logs for specific errors
