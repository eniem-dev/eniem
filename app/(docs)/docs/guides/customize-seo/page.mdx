# Customize SEO

> By the end of this guide, you'll have proper metadata and Open Graph tags for better search visibility.

## Prerequisites

- Completed the [Installation](/docs/getting-started/installation) guide

## Steps

### 1. Update Global Metadata

Edit the metadata in `locales/index.ts`:

```typescript
export const locales = {
  metadata: {
    title: "Your App Name",
    description: "Your app description for search engines",
    keywords: "your, keywords, here",
    author: "Your Name",
    creator: "Your Name",
    publisher: "Your Company",
    applicationName: "Your App",
    twitterCreator: "@yourhandle",
  },
  // ... rest of locales
};
```

### 2. Add Page-Specific Metadata

For each page, use the `createMetadata` utility:

```typescript
export async function generateMetadata() {
  const defaultMeta = await getDefaultMetadata();
  return createMetadata({
    ...defaultMeta,
    title: locales.HomePage.metadata.title,
    description: locales.HomePage.metadata.description,
  });
}
```

### 3. Add Open Graph Image

1. Create a 1200x630 image for social sharing
2. Save it in the root level of app `app/opengraph-image.png`
3. The metadata utility automatically includes it

For page-specific images:

```typescript
openGraph: {
  images: [
    {
      url: "/og-pricing.png",
      width: 1200,
      height: 630,
      alt: "Pricing plans",
    },
  ],
}
```

### 4. Set Up Favicons

Add these files to your `public` directory:

```
public/
├── favicon.ico           # 32x32
├── favicon-16x16.png     # 16x16
├── favicon-32x32.png     # 32x32
├── apple-touch-icon.png  # 180x180
└── site.webmanifest
```

### 5. Configure Environment Variables

```bash
NEXT_PUBLIC_APP_URL=https://yoursite.com
```

## Test It

1. Build your app: `pnpm build`
2. Check that `sitemap.xml` and `robots.txt` are generated
3. Use these tools to validate:
   - [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
   - [Twitter Card Validator](https://cards-dev.twitter.com/validator)
   - [Google Rich Results Test](https://search.google.com/test/rich-results)
